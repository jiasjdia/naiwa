# 奶小蛙桌宠

一个奶家人的 Windows 桌宠。支持眼神跟随、点击 Q 弹、蓄力回弹、拖动、递归分裂、物理反弹堆积、合体，以及有声捧腹大笑。

![奶蛙预览](assets/laugh/f0001.webp)

## 下载运行

直接[下载奶小蛙](https://github.com/jiasjdia/naiwa/releases/latest/download/naixiaowa.exe)，下载完成后双击即可运行，无需解压或安装 Python。

GitHub 会自动改写纯中文附件名，因此下载文件名为 `naixiaowa.exe`，可自行改为 `奶小蛙.exe`；应用名称和图标均为奶小蛙。

适用于 Windows 10/11 x64。所有运行库、动画、眼部素材和音频均已封装在这一个 EXE 中。

## 操作

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 | 待机时眼神轻微跟随 |
| 单击身体 | 点击部位局部 Q 弹 |
| 原地长按后松手 | 约 1.5 秒蓄满，增强回弹 |
| 按住左键移动 | 拎起拖动，放下后回弹 |
| 3 秒内点击身体 10 次 | 完整播放有声大笑 |
| 大笑时 2 秒内再点击 8 次 | 逐只喷出更小的分身，可继续递归分裂 |
| 右键宠物 | 设为本体，打开功能菜单 |
| 菜单“捧腹大笑” / “停止大笑” | 开始 / 停止当前宠物的大笑 |
| 菜单“全部大笑” / “停止全部大笑” | 开始 / 停止全群的大笑，停止后仍会下落 |
| 菜单“复制分身” | 新增一只四档（0.5）的分身 |
| 拖动同档身体重叠后松手 | 合体升一档；异档、一档不能合体 |
| 菜单“归一” | 分身收回当前本体 |
| Ctrl+Alt+C / Ctrl+Alt+V | 复制 / 在鼠标处粘贴分身 |
| Ctrl+Alt+1 | 全体大笑，每只使用独立音轨，可叠加 |
| Ctrl+Alt+Q | 退出全部桌宠 |

最多同时 40 只（含待喷出的预留名额）；每只空闲 3～4 分钟会独立静音大笑。重复启动会显示已有桌宠群。
菜单“大小”只调整当前本体，重启保留最后的大小，不恢复分身。
右键菜单内还可打开完整使用说明。

### 分裂与物理

| 档位 | 大小 | 每波数量 | 可生成档位 |
| --- | --- | --- | --- |
| 一档 | 0.8 | 随机 2～4 只 | 二、三、四档 |
| 二档 | 0.7 | 随机 2～3 只 | 三、四档 |
| 三档 | 0.6 | 2 只 | 四档 |
| 四档 | 0.5 | 不分裂 | — |

每波允许混合档位，每隔 100ms 左右交错喷出一只。分身以 60°～80° 仰角向上弹出，运动速率为原物理过程的 0.75 倍，碰到屏幕边缘、任务栏上方地面和其他宠物后反弹，最终堆积；移走支撑物后会继续下落。

喷射分身从第 54 帧到最后一帧持续循环，声音按同一片段循环，直到使用停止菜单。分身继承来源本轮的发声或静音状态，原宠物保留；拖动分身后悬停，循环和声音继续。普通复制的分身按单次动作播放。
停止、拖动、缩放、重启动作或销毁发射源会取消其未完成喷射，已出生分身继续活动。单击不会停止动作；普通碰撞不会自动合体。旧尺寸会就近归入四档，等距时取较大尺寸。

## 素材范围

当前只启用捧腹大笑。仓库与发布包保留：432 帧 `assets/laugh/*.webp`、眼部图层与几何数据、完整笑声音轨。
音轨预先转换为 48 kHz 双声道 PCM WAV，保留完整长度和开头静音；运行时无需外部音频解码器。
原始 PNG 帧、视频、跳舞素材、旧音轨、缓存、开发运行时和调试截图均不发布。

## 从源码运行

需要 Windows 和带 tkinter 的 Python 3.10～3.13；双击入口固定使用 Python 3.13。

```powershell
python -m pip install -r requirements.txt
python pet_app.py
```

也可双击 `pet.pyw` 无控制台启动。源码模式在项目目录保存设置和日志。
发布的 EXE 在 `%LOCALAPPDATA%\naiwa` 保存大小、日志和实例信息；移动 EXE 或重启仍保留设置，不在下载目录生成文件。
`media_map.json` 保存音量、起始偏移和音画缓冲补偿。

## 打包

在 Windows x64 和 Python 3.13 下构建：

```powershell
python -m pip install -r requirements-build.txt
python tools/build_release.py
# 可选：使用自己的 Windows 图标
python tools/build_release.py --icon path/to/icon.ico
```

输出为 `releases/奶小蛙.exe` 和 `SHA256SUMS.txt`。
默认图标为 `assets/app.ico`，原图保存在 `assets/app-icon.png`。
构建脚本按清单收集素材，不递归复制工作目录；Pymunk 7.3.1 物理引擎、依赖许可和素材哈希清单均包含在 EXE 中。

## 验证

```powershell
python tools/verify_app.py
python tools/verify_app.py --gui
python tools/smoke_release.py releases/奶小蛙.exe
```

测试使用临时设置和静音音频替身；`--gui` 会短暂显示真实 Tk 窗口。
